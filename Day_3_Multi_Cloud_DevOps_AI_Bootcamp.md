# 🚀 Day 3 \| Multi-Cloud + DevOps with AI Bootcamp

Continuing my **DevOps learning journey**, Day 3 focused on
understanding **DevOps fundamentals, tools, SDLC, and practical
automation concepts**.

## 🔹 1. Introduction to DevOps

DevOps brings **Development, Testing, and IT Operations** together to
improve collaboration, automation, and faster software delivery.

We also discussed common challenges DevOps helps address:

➡️ Communication gaps

➡️ Blame between teams

➡️ Manual deployments

➡️ Environment inconsistencies

➡️ Slow release cycles

## 🔹 2. DevOps Tools -- End-to-End

📝 **Planning & Documentation** → Jira, Confluence

🔀 **Code Management** → Git, GitHub

🔨 **Build** → Maven

📦 **Artifact Management** → Nexus

🐳 **Containerization** → Docker

☸️ **Container Orchestration** → Kubernetes

🔄 **CI/CD** → Jenkins, GitLab

🏗️ **Infrastructure as Code** → Terraform, CloudFormation

⚙️ **Configuration & Automation** → Ansible

📊 **Monitoring & Logging** → Prometheus, Grafana, CloudWatch, Splunk,
Datadog

🧪 **Testing** → Selenium, JMeter

💻 **IDE** → Visual Studio Code

## 🔹 3. Practical Concepts

📌 **SDLC:**

Planning → Coding → Building → Testing → Deployment → Monitoring

📌 **Docker:**

Understanding how containerization helps maintain consistency across
different environments.

📌 **GitHub:**

Learning about repository forking, contributing, and **learning in
public**.

📌 **Ansible:**

Understanding automation for operational activities such as patching and
configuration management.

📌 **Project Roles:**

BA → Product Owner → Project Manager → Scrum Master → Team Lead →
Development/Operations Teams

## 💡 Key Takeaway

DevOps is not just about learning individual tools.

It's about understanding **how these tools work together across the
complete software delivery lifecycle.**

**Learning → Practicing → Automating → Building 🚀**
